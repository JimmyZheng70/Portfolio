Shatterpass

Synopsis

Like the game Breakout, but the paddle must match with the color of the ball after each bounce or else lose.

Screenshots

Background

From the Programming Fundamentals Course at UTD, as a final project. Using Python code, I was able to replicate the basic Breakout mechanics, and most importantly create a way to check the colors using true/false statements.
